# HR Analytics Dashboard

## Project Overview

The HR Analytics Dashboard is a Power BI project created to analyze employee data and understand key HR metrics and workforce trends.

The dashboard brings important HR information together in one place, making it easier to review employee attrition, workforce patterns, satisfaction levels, and income-related metrics.

## Project Objective

The main objective of this project is to analyze HR data and present useful information through an interactive Power BI dashboard.

The project focuses on:

* Understanding employee attrition patterns
* Analyzing workforce trends
* Reviewing employee satisfaction
* Analyzing salary and income-related information
* Comparing employee data across departments
* Monitoring important HR metrics
* Supporting data-driven HR analysis

## Dataset

The project uses an HR employee dataset containing information for more than **1,470 employees**.

The dataset contains employee-related information that can be used to analyze:

* Employee attrition
* Workforce characteristics
* Employee satisfaction
* Salary and income
* Department-wise employee information

## Tools & Technologies

The following tools and technologies were used in this project:

* **Power BI** – Dashboard development and data visualization
* **Excel** – Data handling and analysis
* **Power Query** – Data cleaning and transformation
* **DAX** – Creating measures and calculating HR metrics

## Key KPIs

The dashboard includes the following key HR metrics:

* **Total Employees** – Shows the total number of employees included in the analysis.
* **Attrition Rate** – Shows the percentage of employees who have left the organization.
* **Average Monthly Income** – Shows the average monthly income of employees.

## Analysis Performed

The dashboard covers different areas of HR analysis.

### Employee Attrition Analysis

Analyzes employee attrition to understand employee turnover and workforce changes.

### Workforce Analysis

Provides an overall view of the employee workforce and related employee patterns.

### Department-wise Analysis

Allows employee-related information to be compared across different departments.

### Employee Satisfaction Analysis

Helps analyze employee satisfaction levels and understand related workforce patterns.

### Salary and Income Analysis

Analyzes salary and monthly income information to understand employee income trends.

### Employee Trend Analysis

The dashboard helps identify important patterns and trends in the available HR data.

## Dashboard Features

The Power BI dashboard provides:

* Interactive data visualization
* KPI cards for important HR metrics
* Employee attrition analysis
* Workforce analysis
* Department-wise analysis
* Employee satisfaction analysis
* Salary and income analysis
* Interactive filters for exploring the data
* Clear presentation of HR metrics and trends

## How to Run

To view the dashboard:

1. Clone or download this repository.
2. Install **Microsoft Power BI Desktop** if it is not already installed.
3. Open the `HR Analytics Dashboard Solution.pbix` file in Power BI Desktop.
4. Allow the data sources to load if Power BI asks for permission.
5. Refresh the data if required.
6. Use the available filters and dashboard interactions to explore the analysis.
