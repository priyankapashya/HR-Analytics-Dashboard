# HR Analytics Dashboard

## Project Overview

The HR Analytics Dashboard is an interactive Power BI dashboard developed to analyze employee attrition patterns, workforce satisfaction, salary trends, and key employee-related metrics.

The dashboard provides a consolidated view of HR data and helps identify important workforce patterns that can support data-driven HR decision-making.

## Project Objective

The main objective of this project is to analyze HR data and understand important employee and workforce trends.

The dashboard focuses on:

- Analyzing employee attrition patterns
- Understanding workforce satisfaction
- Analyzing salary and income trends
- Monitoring key HR performance indicators
- Comparing employee-related patterns across different areas
- Supporting data-driven workforce decisions

## Dataset

The project uses an HR employee dataset containing information for more than **1,470 employees**.

The dataset is used to analyze employee-related information and identify patterns related to:

- Employee attrition
- Workforce characteristics
- Employee satisfaction
- Salary and income
- Department-wise employee trends

## Tools & Technologies

The following tools and technologies were used in this project:

- **Power BI** – Dashboard development and data visualization
- **Excel** – Data handling and analysis
- **Power Query** – Data preparation and transformation
- **DAX** – Creating measures and calculating key HR metrics

## Key KPIs

The dashboard focuses on the following key performance indicators:

- **Total Employees** – Provides an overview of the total workforce represented in the dataset.
- **Attrition Rate** – Helps monitor the proportion of employees who have left the organization.
- **Average Monthly Income** – Provides an overview of employee income levels.

## Analysis Performed

The project includes the following areas of HR analysis:

### Employee Attrition Analysis

Analyzes employee attrition patterns to understand workforce changes and employee turnover.

### Workforce Analysis

Provides an overview of the employee workforce and helps understand employee-related patterns.

### Department-wise Employee Analysis

Helps compare employee-related information across different departments.

### Employee Satisfaction Analysis

Analyzes workforce satisfaction to understand employee-related satisfaction patterns.

### Salary and Income Analysis

Analyzes employee salary and income trends using relevant HR metrics.

### Employee Trend Analysis

The dashboard helps identify employee-related patterns and trends that can support HR decision-making.

## How to Run

To explore the HR Analytics Dashboard:

1. Clone or download this GitHub repository.
2. Make sure **Microsoft Power BI Desktop** is installed on your computer.
3. Open the `HR Analytics Dashboard Solution.pbix` file in Power BI Desktop.
4. Allow the required data sources to load if prompted.
5. Refresh the data if required.
6. Use the available dashboard interactions and filters to explore the HR analysis.
